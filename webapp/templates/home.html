SLEEC-PATROL

A verifier for social, legal, ethical, empathetic and cultural rules.

Welcome

SLEEC-PATROL checks whether a trained network obeys the rules you wrote for it. You do not need to write any queries: the specification is the input, and every rule in it is checked.

  1. Provide your SLEEC specification — the .sleec file holding the measures, the constants and the rules.
  2. Provide the neural network — the .onnx file whose inputs are the measures and whose outputs are the output events, in declaration order.
  3. Read the compliance report — every rule is reported as compliant, violated or unverified, and a violated rule comes with the counter-example that breaks it: the values themselves, and a scene drawn from them where the environment is one the tool can picture.
